# Student Marks Calculator

## Purpose

This is a simple Python project for calculating student marks.

## What it does

- Takes student name
- Takes marks
- Calculates total marks
- Calculates average marks

## How to run

Run the following command:

python student_marks.py

## Example Input

Student name: Rahul
Maths: 80
Python: 90
English: 85

## Example Output

Student: Rahul
Total: 255
Average: 85.0
