Student Marks Calculator

A beginner-friendly Python project that calculates a student's total marks, average marks, and pass/fail result.

Project Overview

The Student Marks Calculator is a simple command-line application built using Python. It accepts marks for three subjects, calculates the total and average, and determines whether the student has passed or failed.

Features
Accepts the student's name.
Takes marks for Maths, Python, and English.
Calculates total marks.
Calculates average marks.
Displays the student's result as Passed or Failed.
Technologies Used
Python 3
Git
GitHub
How to Run
Clone or download this repository.
Open the project folder in Command Prompt or a terminal.
Run the following command:
python student_marks.py
Example Input
Enter student name: Rahul
Enter Maths marks: 80
Enter Python marks: 90
Enter English marks: 85
Example Output
Student: Rahul
Total: 255.0
Average: 85.0
Result: Passed
Passing Criteria
Average marks of 40 or above: Passed
Average marks below 40: Failed
