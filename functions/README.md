*# Python Functions Practice*



*## Purpose*



*This project is a simple Student Marks Calculator developed using Python functions. It takes marks for multiple subjects and calculates the total, average, highest marks, lowest marks, percentage, grade, and passed or failed subject count.*



*## What It Does*



*- Takes the number of subjects from the user.*

*- Accepts marks for each subject.*

*- Stores the marks in a list.*

*- Calculates total marks.*

*- Calculates average marks.*

*- Finds the highest marks.*

*- Finds the lowest marks.*

*- Calculates percentage.*

*- Displays the grade.*

*- Counts passed and failed subjects.*



*## Functions Used*



*| Function | Purpose |*

*|---|---|*

*| `total\_marks(l)` | Calculates the total marks |*

*| `avg\_marks(l)` | Calculates and displays the average |*

*| `highest\_marks(l)` | Finds the highest marks |*

*| `lowest\_marks(l)` | Finds the lowest marks |*

*| `percentage(l)` | Calculates the percentage |*

*| `grade\_system(l)` | Displays the grade based on percentage |*

*| `count\_passed\_std(l)` | Counts passed and failed subjects |*



*## Grading System*



*| Percentage | Grade |*

*|---|---|*

*| Above 90 | A |*

*| Above 70 | B |*

*| Above 50 | C |*

*| Above 30 | D |*

*| 30 or below | E |*



*## Passing Condition*



*A subject is considered passed when the marks are 25 or above.*



*Marks below 25 are considered failed.*
